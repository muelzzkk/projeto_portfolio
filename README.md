# 💻 Portfólio Web — Web II

Projeto desenvolvido para a disciplina de **Web II**, com o objetivo de aplicar conceitos de desenvolvimento web na criação de um portfólio pessoal responsivo e interativo.

O projeto apresenta informações sobre os desenvolvedores, habilidades, projetos realizados e um formulário de contato.

## 👨‍💻 Desenvolvedores

**Marco Antônio e Samuel**

Projeto acadêmico desenvolvido como atividade da disciplina de **Web II**.

## 🎯 Objetivo

Desenvolver uma página web moderna, responsiva e interativa, aplicando conceitos fundamentais de desenvolvimento front-end.

O portfólio foi desenvolvido para apresentar:

* Informações sobre os desenvolvedores
* Habilidades e tecnologias
* Projetos desenvolvidos
* Formulário de contato
* Interface responsiva para diferentes dispositivos

## 🛠️ Tecnologias utilizadas

* **HTML5** — Estrutura semântica da página
* **Tailwind CSS** — Estilização e criação do layout responsivo
* **CSS3** — Estilos personalizados, animações e efeitos visuais
* **JavaScript** — Interatividade e manipulação do DOM
* **Git e GitHub** — Versionamento e hospedagem do projeto

## ✨ Funcionalidades

### 📱 Design responsivo

A interface se adapta a diferentes tamanhos de tela, incluindo:

* Computadores
* Tablets
* Smartphones

### ☰ Menu responsivo

O menu de navegação possui comportamento diferente de acordo com o tamanho da tela, utilizando um menu específico para dispositivos móveis.

### 🎠 Carrossel de projetos

A seção de projetos possui um carrossel interativo que permite:

* Avançar para o próximo projeto
* Voltar para o projeto anterior
* Selecionar um projeto através dos indicadores

### 🔎 Modal de projetos

Ao selecionar um projeto, é exibida uma janela modal contendo:

* Nome do projeto
* Descrição
* Tecnologias utilizadas

O modal também pode ser fechado através do botão de fechamento, clicando fora da janela ou pressionando `ESC`.

### 📩 Formulário de contato

O formulário possui validação utilizando JavaScript, verificando:

* Nome preenchido
* Quantidade mínima de caracteres no nome
* Formato do e-mail
* Mensagem preenchida
* Quantidade mínima de caracteres na mensagem

## 📁 Estrutura do projeto

```text
projeto_portfolio/
│
├── index.html
│
├── css/
│   └── style.css
│
└── js/
    └── script.js
```

### `index.html`

Responsável pela estrutura e conteúdo da página.

Contém os estilos personalizados, animações, efeitos visuais e ajustes de responsividade.

### `js/script.js`

Responsável pelas funcionalidades interativas da página, como:

* Menu mobile
* Cabeçalho dinâmico
* Carrossel
* Modal
* Validação do formulário

O projeto utiliza uma identidade visual moderna, baseada em tons escuros com detalhes em **ciano e roxo**, proporcionando contraste e destaque para as principais informações.

## 🚀 Como executar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/muelzzkk/projeto_portfolio.git
```

### 2. Acessar a pasta

```bash
cd projeto_portfolio
```

### 3. Executar

Abra o arquivo `index.html` em um navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto durante o desenvolvimento.
